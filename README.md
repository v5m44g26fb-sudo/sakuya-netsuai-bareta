# 💗 サクヤと熱愛バレた件

NCT WISHのサクヤを題材にした、スマホ風SNSファンゲーム（単一HTML＋画像/動画アセット、フレームワークなし）。

**これは実在の人物を題材にした創作フィクション（ファンメイド作品）です。登場人物の発言・交際等の出来事は全て創作であり、実在の内容とは関係ありません。ツアー日程・会場・リリース実績等の史実データは公開情報に基づきます。**

▶ **プレイ:** https://v5m44g26fb-sudo.github.io/sakuya-netsuai-bareta/

## あらすじ
2027年1月、韓国旅行でソウルにいた「なお」（サクヤペンの一般ファン）がマッチングアプリで出会った「ソウ」。言葉選びの丁寧さと不思議な感性に惹かれ、ソウル最終日に初めて会うと――彼は本物のNCT WISHサクヤだった。1/17に帰国して遠距離が始まり、代々木（2/26〜28）・神戸（3/5〜7）の日本公演で再会を重ねるが、神戸最終日の夜、海沿いで撮られた写真がスクープに。炎上と事務所の声明をめぐる選択で、結末が変わる。

## システム
- 全10話（第1話〜第7話＋炎上編2話＋声明編）＋エンディング3種（公表END／静かに続けるEND／ほろ苦いEND）
- ゲージ3種：信頼度／炎上度／ファンの温度。選択肢で変動し、エンディング条件に直結
- クリア後：サクヤとのフリーチャット解放（キーワード応答22種＋エンディング別トーン）
- セーブはlocalStorage自動保存。ボイス収録済み（サクヤの声を重要場面7箇所に実装：正体明かし、深夜の電話3本、報道場面2本、エンディング。対象のセリフ・通話に「▶ ボイス」ボタンが出る）

## 実装アプリ（2026/2027年仕様の実物寄せ）
- ロック画面（実時刻、通知カード）／ホーム（Liquid Glassウィジェット、ゲージ表示）
- マッチングアプリ風チャット→LINE現行風（既読の時間差、入力中表示は文字量連動・深夜は遅延、時刻はシーン内で自然進行）
- Instagram現行風（ストーリー全画面、コメントシート、いいね万表記、リール動画）
- X現行風（トレンド切替：通常時→炎上時、スクープ投稿）
- ニュース（通常記事＋スクープ記事＋声明記事）
- TikTok（**本物の動画**：公式MVプレビュー〈iTunes〉から作成した縦型クリップ3本、タップで音ON切替）
- 写真（動画1点含む）、カレンダー（2027年1〜3月・史実日程）、サクヤ観察メモ（10件＋ENDコレクション）、電話（スライド応答→通話タイマー）

## 素材について
- 画像：Pinterest／Instagram系の掲載写真、KProfiles等のプロフィール写真、メディア掲載写真。個人写真はv12で最新期に刷新（サクヤ＝『COLOR』コンセプト公式写真・『I SPY』Confused Boy公式ティーザー写真（2026年9月）、メンバー＝KProfiles掲載の2025年プロフィール写真）。なおのアバターには本人の写真を使用していません（イニシャルアイコン）
- 動画：NCT WISH公式ミュージックビデオの公式プレビュー（iTunes）から作成したクリップ。TikTok公式動画は取得環境のIPブロックにより直接収録できず、MV動画をTikTok UIで再生する形に代替
