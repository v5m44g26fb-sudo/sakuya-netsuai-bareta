# 💗 サクヤと熱愛バレた件

NCT WISHのサクヤを題材にした、スマホ風SNSファンゲーム（単一HTML＋画像/動画アセット、フレームワークなし）。

**これは実在の人物を題材にした創作フィクション（ファンメイド作品）です。登場人物の発言・交際等の出来事は全て創作であり、実在の内容とは関係ありません。ツアー日程・会場・リリース実績等の史実データは公開情報に基づきます。**

▶ **プレイ:** https://v5m44g26fb-sudo.github.io/sakuya-netsuai-bareta/

## あらすじ
2027年1月、韓国旅行でソウルにいた「なお」（サクヤペンの一般ファン）がHelloTalk（言語交換アプリ）で出会った「빵돌이」。なおはソウル旅行を前に韓国語を勉強中で、ソウル在住の日本人である彼のモーメンツを見つけて声をかけた。言葉選びの丁寧さと不思議な感性に惹かれ、ソウル最終日に初めて会うと――彼は本物のNCT WISHサクヤだった。1/17に帰国して遠距離が始まり、代々木（2/26〜28）・神戸（3/5〜7）の日本公演で再会を重ねるが、神戸最終日の夜、海沿いで撮られた写真がスクープに。炎上と事務所の声明をめぐる選択で、結末が変わる。

## システム
- 全10話（第1話〜第7話＋炎上編2話＋声明編）＋エンディング3種（公表END／静かに続けるEND／ほろ苦いEND）
- ゲージ3種：信頼度／炎上度／ファンの温度。選択肢で変動し、エンディング条件に直結
- クリア後：サクヤとのフリーチャット解放（キーワード応答22種＋エンディング別トーン）
- セーブはlocalStorage自動保存。ボイス収録済み（サクヤの声を重要場面7箇所に実装：正体明かし、深夜の電話3本、報道場面2本、エンディング。対象のセリフ・通話に「▶ ボイス」ボタンが出る）
